# MindMate AI 📱

MindMate AI is an Android application that leverages on-device AI (Llama 3.2) to provide intelligent academic and productivity assistance. The app enables users to summarise content, generate study plans, and interact with their notes using natural language.

## 🚀 Features
- 📄 Text summarisation
- 🧠 Context-aware Q&A (planned)
- 📅 AI-generated study plans
- 🔒 Fully on-device processing (privacy-focused)
- ⚡ Zero-latency responses

## 🏗️ Architecture
The app follows **MVVM architecture**:

UI → ViewModel → AI Manager → On-device LLM

## 🤖 AI Integration
Currently, AI responses are simulated. The architecture is designed to integrate **Llama 3.2 via Android AI Edge SDK** for on-device inference.

## 🛠️ Tech Stack
- Java (Android)
- Android Studio
- MVVM Architecture
- Room Database (planned)
- Google AI Edge SDK (planned)

## 📦 Setup Instructions
1. Clone the repository
2. Open in Android Studio
3. Build and run on emulator/device
